# 더치페이 계산기

총 결제 금액과 참석자별 분담 가중치를 입력해 각자 부담할 금액을 계산하는 모바일 친화형 웹앱입니다.

## 주요 기능

- 총 결제 금액 입력
- 참석자 이름 추가·삭제 및 인원수에 맞춘 입력칸 생성
- 동일 분담 또는 가중치 기반 분담 계산
- 1원, 10원, 100원, 1,000원 단위 정산
- 계산 결과 복사
- 모바일 화면 대응 및 입력값 검증

## 실행 방법

1. 저장소에서 `index.html` 파일을 내려받습니다.
2. 파일을 더블 클릭해 Chrome, Edge 등 웹 브라우저에서 엽니다.
3. 총 금액과 참석자 정보를 입력한 뒤 **얼마씩 낼지 계산하기**를 누릅니다.

별도의 설치, 서버, 로그인, API 키가 필요하지 않습니다.

## 사용 방법

1. 총 결제 금액과 인원수를 입력합니다.
2. **인원수만큼 이름 입력칸 만들기**를 누르거나 참석자를 직접 추가합니다.
3. 각 참석자의 분담 가중치를 설정합니다. 모두 똑같이 나누려면 1로 둡니다.
4. 정산 단위를 선택하고 계산합니다.
5. 필요하면 결과 복사하기로 정산 내역을 공유합니다.

## 정산 방식

각 참석자의 가중치 비율로 금액을 배분합니다. 마지막 참석자 외의 금액은 선택한 정산 단위로 내림 처리하고, 남은 금액은 마지막 참석자에게 배분하여 총합이 결제 금액과 일치하도록 합니다. 따라서 마지막 참석자의 부담액은 다른 사람과 조금 다를 수 있습니다.

입력한 이름과 금액은 서버로 전송되지 않습니다. 브라우저 화면에서 계산만 수행합니다.
